# Medicare Data Analysis

## Project Overview

An end-to-end analysis of 5M+ Medicare hospital discharges across 3K+ hospitals using SQL and Power BI.

This project covers the complete data analysis workflow, including data cleaning, exploratory data analysis (EDA), and interactive dashboard development. The analysis transforms large-scale Medicare inpatient data into meaningful insights through SQL queries and Power BI visualizations.

---

## Tools & Technologies

- **SQL** — Data cleaning and exploratory data analysis
- **Power BI** — Interactive dashboard and data visualization

---

## Project Workflow

### 1. Data Cleaning

The raw Medicare inpatient data was cleaned and prepared using SQL.

Key data preparation tasks include:

- Cleaning and preparing the dataset for analysis
- Handling missing and inconsistent data
- Standardizing data where required
- Preparing the data for further analysis and visualization

### 2. Exploratory Data Analysis (EDA)

SQL queries were used to explore the dataset and identify meaningful patterns and insights across Medicare hospital discharges.

The analysis examines different aspects of the data to understand trends, comparisons, and distributions.

### 3. Power BI Dashboard

The cleaned data was used to build an interactive Power BI dashboard.

The dashboard is organized into three analysis pages:

- **Overview** — High-level summary and key insights
- **Hospital Analysis** — Analysis focused on hospitals and providers
- **Diagnosis Analysis** — Analysis focused on diagnoses and related healthcare patterns
